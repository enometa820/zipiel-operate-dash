## 3. 재현 절차 (그대로 복붙 → 갱신)

### 3.1 코퍼스 빌드 (history + 상위 스레드)

```bash
# 1) 슬랙 스킬 디렉터리로 이동(토큰 자동 로드)
cd ../zipiel-cs-demo/.claude/skills/zipiel-slack

# 2) 연결 확인 + 채널 전수 히스토리 저장
python slack.py whoami
python slack.py history C0APNDK4QKW --limit 300 > /tmp/slack-history.txt   # (실제론 scratchpad 경로 사용)

# 3) 답글 많은 스레드 ts 추출(상위 N)
grep -oE "\[\+[0-9]+ 답글 ts=[0-9.]+\]" /tmp/slack-history.txt | sort -t+ -k2 -rn | head -20

# 4) 코퍼스 = 히스토리 + 각 스레드 펼침
CORPUS=/tmp/slack-corpus.txt
cat /tmp/slack-history.txt > "$CORPUS"
for ts in <위에서 뽑은 ts 목록>; do
  echo -e "\n===== THREAD ts=$ts =====" >> "$CORPUS"
  python slack.py thread C0APNDK4QKW $ts >> "$CORPUS"
done
```

> 이번 실행에 펼친 스레드 ts 20개(참고): `1782295523.789039 1781600760.228189 1782180711.742739 1781860460.139249 1781490639.149459 1781521303.706679 1781253082.228169 1781847109.882959 1781832020.641379 1782180560.258139 1781857179.811819 1781744306.023889 1781856760.394139 1781840819.387759 1781861102.927179 1781774722.398249 1781658178.603499 1781591673.643739 1782351537.312839 1782277385.497779`

## 4. 갱신·확장 방법

- **최신화(새 메시지 반영)**: 3.1을 다시 실행(채널·기간만 바꿔 history 재취득) → 새 ts로 코퍼스 재빌드 → 3.2 재실행. `--limit`를 늘리면 더 과거까지.
- **다른 채널 추가**: `slack.py channels`로 ID 확인 후 같은 절차. 관련 채널(스킬 SKILL.md §2 채널지도) 예: `퍼포먼스-마케팅`·`데이터-대시보드`·`ai-활용-효율화-자동화`·`crm`·`글로벌-시딩`.
- **다른 조사 질문**: 워크플로우의 `LENSES` 배열 프롬프트만 교체(예: 경쟁사·가격·캠페인 성과 렌즈).
- **키워드 추적**: 채널 넘나드는 주제는 `python slack.py search "<키워드>"`로 교차 → 나온 ts를 `thread`로 펼쳐 코퍼스에 추가.
